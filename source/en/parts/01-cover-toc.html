Dual-Brain System

A Multi-Model Collaborative Cognition Framework · From Neural Mechanisms to a Simulation Blueprint

The primary purpose of this proposal is not to build a memory store, but to let multiple models divide the labor so that the context the Main Brain must read each round is compressed to a minimum. Memory is not a warehouse; it is the infrastructure that lets the Main Brain make better judgments within relationships. Encoding, consolidation, retrieval, reconsolidation, forgetting, decision-making, and social relationship memory are all links on this through-line.
